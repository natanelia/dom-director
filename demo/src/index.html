THE HONEST VERSION
A proof of the feeling.
This standalone demo is a deliberately controlled app, not a universal wrapper for arbitrary websites. All workspace data is fictional and all actions stay in memory.
Working in this prototype
DOM camera framing, three easing curves, visual cursor, prepared synthetic narration, captions, transcript, seeking, playback speed, mode switching, and a real interactive checkpoint.
Not claimed here
The reusable SDK, arbitrary-app compatibility, production agent integration, full action permissions, video export, or completion of the library milestones.
Accessibility and control
Use Space to play or pause and Escape to take over. Standard keyboard controls work. “Motion off” keeps the camera still. Captions and transcript are available without audio. Narration is an intentionally simple local synthetic placeholder, not a final production voice.
No surprise network calls
No external fonts, libraries, tracking, AI services, or account connection. The download is a self-contained HTML file with its own audio.
